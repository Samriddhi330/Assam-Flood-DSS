# Assam Flood DSS

**An Explainable Multi-Factor Framework for Revenue Circle-Level Flood
Impact Assessment and Relief Prioritization in Assam**

A two-stage Decision Support System (DSS):

- **Stage 1 — Predictive Engine**: gradient-boosted models predict
  next-month flood impact for every Revenue Circle in Assam from hazard,
  exposure and vulnerability features, explained with TreeSHAP.
- **Stage 2 — Prescriptive Engine**: an Integer Linear Program (ILP)
  allocates limited relief resources (boats, food, medical teams) from
  relief bases to the circles that need them most, subject to capacity and
  travel-distance constraints.

```
Historical Flood Data + Rainfall + River Info + Population + Infrastructure
                              |
                     Machine Learning (Stage 1)
                              |
                 Next-Month Flood Impact Probability
                              |
                      TreeSHAP Explanations
                              |
                  Relief Demand per Revenue Circle
                              |
              Integer Linear Programming (Stage 2)
                              |
              Boat / Food / Medical-Team Allocation Plan
```

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
```

## Run the full pipeline

```bash
python src/pipeline_run.py
```

This will (re-using cached files where they already exist):
1. Generate placeholder geographic reference data (`data/circle_centroids.csv`,
   `data/relief_bases.csv`) if not already present.
2. Train and compare Logistic Regression, Random Forest, XGBoost and
   CatBoost on a temporal (never random) train/test split, and save the
   best model by F1 Score to `models/`.
3. Compute global and per-circle TreeSHAP explanations.
4. Score the most recent month and estimate relief demand per circle.
5. Solve the ILP relief-allocation problem and save the plan.

Force retraining even if a model already exists:

```bash
python src/pipeline_run.py --retrain
```

Run any stage individually, e.g.:

```bash
python src/train_model.py
python src/explain_shap.py
python src/predict_impact.py
python src/optimize_relief.py
```

## View the dashboard

```bash
streamlit run dashboard/app.py
```

Shows an interactive map (impact-coloured circles, relief bases, planned
boat routes), the full priority ranking with SHAP reasons, and the
resource-fulfilment table per circle.

## Important note on the geographic data

`data/circle_centroids.csv` and `data/relief_bases.csv` are generated by
`src/generate_geo_reference.py` as **clearly-labelled placeholder
geography** -- the modelling dataset does not ship with GIS coordinates.
Circle centroids are deterministic points inside Assam's bounding box; base
locations are real Assam towns with assumed relief capacities. To move to
production, replace both CSVs with real Revenue Circle centroids (e.g.
exported from the shapefiles used during EDA) and real ASDMA/SDRF base
data -- the column names are all that the rest of the pipeline depends on.
